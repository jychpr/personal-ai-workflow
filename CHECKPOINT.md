## Working agreement
This chat plans, reviews, interprets results and writes prompts; it never writes code or creates
files in the repository. Claude Code executes in the repository on the workstation. Cowork does
document work in a separate folder, from copies of DECISIONS.md and CHECKPOINT.md placed in its
inputs/ by hand [state], and never touches the repository. All numbers originate in results/ (D8).
Model seats: D166 as amended by D172(a) and D184(h): ideation here on Opus, cheap measurements on
Opus in Claude Code, Fable for the deep design and implementation of a method that has cleared
ideation and its cheap checks, one Fable session taking every live candidate at once.

Every prompt from this chat opens with a header naming, in order: the surface (Claude Code,
Cowork, or a design chat), the model and effort (D166a), and whether it is a new session or a
continuation, naming which one if it continues. Example: "Claude Code - Fable, maximum effort - new
session"; or "Continue the {PHASE} session". [state] The header is shown as a heading above
the copy block, and the model is named again inside the prompt for the run record (D166a). Each
prompt then carries, as the phase prompts in this record do: what to read and in what order; what
to do, numbered; the acceptance checks; the stop conditions; a time box; where results are
written; and, for anything that will be read as evidence, the reading rule fixed before the run
(D5, D23). Long jobs are launched detached (D156a). A session that must change a pre-registered
file stops and reports instead (D166c). Cowork prompts first check that the copies in inputs/ carry
the latest decision, and stop if they do not [state].
