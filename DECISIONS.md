# DECISIONS - overrides HANDOFF.md where they conflict. Human-owned.

> Format: one entry per decision, `Dn. <decision>`, under the date it was made. Longer entries are
> split into lettered parts and cited as e.g. D22(b). The log is append-only: an entry that amends
> or retracts an earlier one is a new entry, never an edit. Content is removed in this public
> version; the examples below are illustrative, not real entries.

```text
Dn. Environment approved: conda env {ENV_NAME}, Python 3.10, {FRAMEWORK} {VERSION}, with a named fallback version; exact versions go in results/ENV.md.

Dn. {BASELINE} reproduced at {SCORE} against its published {SCORE} (results/repro_{BASELINE}.json, commit {HASH}). Within {TOLERANCE}: reproduction accepted, no tuning.

Dn. What a null result means, written before the run: if {METHOD} does not clear the threshold T on the report split, the baseline table stands and the direction is chosen on other evidence.

Dm. Dk retracted: its reading was an artifact of {CAUSE}, not a property of the model. Later entries cite this one instead.

Dn. {METHOD} gate FAIL.
(a) {METHOD} is dead; its Outcome section is written in METHOD{N}.md.
(b) What the failure shows: {FINDING}.
(c) Next: {NEXT_STEP}, pre-registered before it runs.
```
